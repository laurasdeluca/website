# Laura S. DeLuca — academic website (v8)

Static website for **https://laurasdeluca.com/**. Open `index.html` to preview locally.

## Publish with Vercel
1. Create or open a Vercel project and deploy the contents of this folder (the folder containing `index.html`). For a GitHub repo, put the files at the repo root; framework preset **Other**, no build command.
2. In Vercel: **Project → Settings → Domains**, add `laurasdeluca.com` and `www.laurasdeluca.com`. Choose the apex domain as primary and redirect `www` to it.
3. Register `laurasdeluca.com` with a domain registrar if it is available and you do not already own it.
4. Follow the **specific DNS records shown by Vercel** for your project at your domain registrar. Do not assume an IP address or CNAME without checking Vercel's current instructions. Wait for DNS and SSL certificate activation.
5. Test the CV download, navigation, publication filters and mobile view after deployment.

**Important:** This ZIP does not purchase, reserve, or connect the domain. Availability and ownership have not been verified.

## Content and assets
- `index.html`: design and page markup; canonical URL is set to laurasdeluca.com.
- `site.js`: publications, teaching, talks, awards, projects and service.
- `headshot.jpg`, `queen-engraving.jpg`: images. The queen illustration is decorative, not a verified archival print.
- `Laura-S-DeLuca-CV.pdf`: downloadable CV.
- Footer social links currently search for your name rather than point to verified personal profiles. Replace their `href` attributes with your exact profile links when ready.
- Funding names are styled text, not verified official logos.
